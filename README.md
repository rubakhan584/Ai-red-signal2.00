# AI-red-signal2.00

এটি একটি অ্যান্ড্রয়েড অ্যাপ্লিকেশন প্রজেক্ট যা এআই (AI) ব্যবহার করে রেড সিগন্যাল বা ট্রাফিক সিগন্যাল শনাক্ত করতে সাহায্য করে। 

## বৈশিষ্ট্য (Features)
*   এআই ইমেজ প্রসেসিং
*   রিয়েল-টাইম সিগন্যাল ডিটেকশন
*   ইউজার ফ্রেন্ডলি ইন্টারফেস

## ব্যবহৃত টেকনোলজি (Tech Stack)
*   **Language:** Java / Kotlin
*   **IDE:** Android Studio
*   **AI Framework:** (যেমন: TensorFlow Lite বা OpenCV - আপনি যা ব্যবহার করেছেন)

## কিভাবে চালাবেন (How to Run)
১. আপনার কম্পিউটারে Android Studio ইনস্টল করুন।
২. এই রিপোজিটরিটি ক্লোন (Clone) করুন অথবা ডাউনলোড করুন।
৩. Android Studio-তে প্রজেক্টটি ওপেন করুন।
৪. Gradle সিঙ্ক (Sync) হওয়া পর্যন্ত অপেক্ষা করুন।
৫. একটি এমুলেটর (Emulator) বা ফিজিক্যাল ডিভাইস কানেক্ট করে 'Run' বাটনে ক্লিক করুন।
